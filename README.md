# 🩺 Sistema Alcance — Gestão Inteligente e Territorialização na Atenção Primária à Saúde (APS)

[![GitHub Pages](https://img.shields.io/badge/Status-Online-brightgreen)](https://alcancedab.github.io/sistemaalcance/)
[![Licença](https://img.shields.io/badge/Licença-MIT-blue.svg)](LICENSE)
[![SUS](https://img.shields.io/badge/APS-SUS-green.svg)](https://alcancedab.github.io/sistemaalcance/)

O **Sistema Alcance** é uma plataforma desenvolvida para otimizar a gestão de saúde pública municipal, focada na **territorialização**, geoprocessamento e análise de indicadores da **Atenção Primária à Saúde (APS)** no âmbito do Sistema Único de Saúde (**SUS**).

📍 **Acesse a aplicação:** [alcancedab.github.io/sistemaalcance](https://alcancedab.github.io/sistemaalcance/)
